# 🌱 Agrinho 2026 — Agro Forte, Futuro Sustentável

## Tema

**Agro forte, futuro sustentável: equilíbrio entre produção e meio ambiente.**

## Assunto Escolhido

**Manutenção sustentável de máquinas agrícolas.**

## 👨‍🎓 Sobre o Projeto

Este projeto foi desenvolvido para o Concurso Agrinho 2026, na categoria de Programação Web.

O site apresenta informações sobre a importância da manutenção sustentável de máquinas agrícolas e mostra como a profissão de mecânico pode contribuir para uma produção agrícola mais eficiente e responsável.

A proposta é demonstrar que produtividade e preservação ambiental podem caminhar juntas.

## 🎯 Objetivo

O objetivo do projeto é apresentar, de forma simples e interativa, como a manutenção correta de máquinas agrícolas pode:

- Reduzir desperdícios;
- Evitar vazamentos e contaminações;
- Aumentar a vida útil dos equipamentos;
- Melhorar a eficiência das máquinas;
- Contribuir para uma agricultura mais sustentável.

## 💡 Interatividade

O site possui um **quiz sobre sustentabilidade no campo**, desenvolvido com JavaScript.

O usuário responde às perguntas e recebe sua pontuação no final.

Tenho interesse na profissão de **mecânico**.
